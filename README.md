# Bhumika Mishra — Cybersecurity Portfolio

Fast, responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Deploy on GitHub Pages
1. Upload all files to your repository.
2. Keep `index.html` at the repository root.
3. Open GitHub → Settings → Pages.
4. Select the main branch and root folder.
5. Save.

## Resume
Place your PDF as `resume.pdf` in the repository root so the Download Resume button works.
